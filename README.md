# 双色球盲测实验室 / SSQ Lab

一个“选号小游戏 + 严格时间外盲测”的本地项目。它优先保证真实数据、可复现采集和无未来信息泄漏，而不是把随机开奖包装成可预测系统。

## 先看结论

- 真实数据：`3166` 期，`2006001`（2006-01-01）→ `2026133`（2026-11-19）。
- 数据来源：中彩网官方开奖信息 + 中国福彩官网；`2013` 年至今 `2091` 期双源逐期复核，红蓝球和可选一等奖数据均为 `0` 不一致。`2006–2012` 的 `1075` 期当前只有中彩网可用，明确标记为“单源结构校验”，不冒充双源确认。
- 常规盲测：验证段 `2019-11-20` → `2021-11-19`（`284` 期），测试段 `2021-11-20` → `2026-11-19`（`754` 期）。
- 2015 时间外实验：只用 `2013-01-01` → `2014-12-31` 选模，冻结后在 `2015` 年（`154` 期）盲测；用户指定的随机 10 期由固定种子 `20261120` 抽取。
- 2015 随机 10 期：实验集成 Top-10 红球覆盖 `10/10`；单注任何奖级 `1/10`；单注头奖 `0/10`；蓝球命中 `1/10`。
- 上述 `10/10` 覆盖的 95% Wilson 区间是 `[72.25%, 100%]`，下界没有达到 90%。10 期样本无论全中与否，都不足以证明 90% 下限。
- 2015 全年 `154` 期：实验集成 Top-10 覆盖 `140/154 = 90.91%`，95% 区间 `[85.32%, 94.51%]`；随机基线 `144/154 = 93.51%`，区间 `[88.46%, 96.43%]`。
- 近 5 年测试段：实验集成 Top-10 覆盖 `92.44%`，区间 `[90.33%, 94.12%]`；但验证段没有模型通过显著性门槛，严格模式仍回退随机基线。两者单注头奖均为 `0`。
- 默认 `10` 注覆盖组合保证票面唯一、使用 `10` 个不同蓝球，并最大化红球“四中以上”结果邻域；精确的至少中一个奖概率为 `64.34%`，独立随机买 10 注的期望为 `50.07%`。头奖概率仍只等于 `10 / 17,721,088`。

## 90% 到底是什么

公平双色球的每期开奖近似独立随机：

- 单注 `6+1` 头奖概率固定为 `1 / 17,721,088`。
- 任意固定 `10` 个红球覆盖当期中至少一个红球的概率是
  `1 - C(23,6)/C(33,6) = 90.8857%`。
- 因而“Top-10 红球池至少命中一个开奖红球”可以在长期期望上接近或达到 90%，但这不是单注中奖率，也不能证明模型有预测能力；任何固定 10 个红球都有同样的组合覆盖属性。
- 单注 `6+1` 与真实结果完全一致、或每期都达到 90% 单注命中率，在公平规则下无法通过历史数据或机器学习实现。

本项目将“Top-10 覆盖率”和“单注真实命中”严格分开展示。历史数据飞轮用于在线更新、校准记录、发现泄漏和验证流程，不会从独立随机事件中制造未来信息。

## 预算内覆盖组合

当目标从“猜中下一期号码”改为“同等注数下至少有一张票中奖”，可以做真实且可证明的优化：

- 每张票必须是不同的 `6+1` 组合，避免浪费头奖覆盖。
- 前 `16` 注使用不同蓝球。因为六等奖只要求蓝球命中，`16` 注覆盖全部蓝球可以数学保证至少一注中奖，但成本 `32` 元、最低奖金通常只有 `5` 元，不代表盈利。
- 红球组合用贪心覆盖算法减少四中以上结果邻域的重叠，提高四至五等奖的联合覆盖。
- 默认 10 注当前精确概率：至少中一个奖 `64.3366%`，前三等奖 `0.0100445%`，头奖 `0.00005643%`，约 `1 / 1,772,109`。
- 独立随机买 10 注的期望：至少中一个奖 `50.0683%`。这部分提升来自蓝球去重与组合覆盖，不是从历史开奖预测未来。

所有概率直接枚举双色球完整结果空间的等价组合集合计算，不使用已知开奖结果拟合。生成逻辑在 `src/lottery_lab/portfolio.py`，仪表盘首页会展示票单、成本和精确概率。

## 99% 极限审计

“前三等奖”按一等奖（6+1）、二等奖（6+0）、三等奖（5+1）合并计算：

- 单注前三等奖概率：`(1 + 15 + 162) / 17,721,088 = 178 / 17,721,088 = 0.001004%`，约 `1 / 99,557`。
- 单注头奖概率：`1 / 17,721,088`。
- 当前 Top-10 红球 + Top-4 蓝球候选池达到“至少 5 红且蓝中”的概率只有 `0.1356%`。

2008-01-01 → 2026-11-19 的 `2859` 期严格 walk-forward 回放结果：

- 8 个模型单注头奖合计命中 `0` 次。
- 本次重跑的最好模型前三等奖命中 `0 / 2859 = 0%`，95% Wilson 区间上界约 `0.129%`；零命中不等于未来必然为零，只说明没有观察到可复现的高命中能力。
- 最好的 Top-10 + Top-4 候选池命中 `11 / 2859 = 0.3847%`，95% 区间 `[0.215%, 0.688%]`。
- 这仍然比 99% 低了三个数量级；一次三等奖命中属于稀有事件，不是稳定预测能力。

如果目标改成“至少有一次前三等奖”，单注独立尝试约需 `458,474` 期；按不同票随机覆盖约需 `452,594` 张，面值 `905,188` 元。若目标是头奖，99% 覆盖约需 `17,543,878` 张不同彩票，面值 `35,087,756` 元。这些是组合覆盖，不是预测能力。

候选池要达到 99% 前三等奖覆盖，即使蓝球全选 16 个，也至少需要 `32` 个红球；这已经等价于放弃单注预测。完整计算见 `reports/extreme_audit.json`，可运行 `make extreme` 复现。

### 未来 X 期规划

`src/lottery_lab/campaign.py` 将同一覆盖口径扩展到未来 `X` 期：每期从完整票面空间均匀抽取不重复组合，跨期按独立开奖复合，反解达到 99% 至少一次命中的最低每期注数。默认报告覆盖 `10 / 52 / 100 / 500 / 1000` 期，输出在 `reports/campaign_plan.json` 和 `web/data/campaign.json`，可运行 `make campaign` 重算。若使用模型排序后手工优化票面，应改用 `portfolio.py` 对具体票单做精确联合覆盖计算，不能直接把这里的均匀抽样概率当成任意票单的保证。

- 前三等奖及以上：无论把注数分布在 10 期还是 1000 期，达到 99% 的总覆盖规模约为 `45.8` 万张，成本约 `91.6` 万元。
- 头奖：100 期仍需约 `79.8` 万张，总成本约 `1.60` 亿元；1000 期仍需约 `8142` 万张，总成本约 `1.63` 亿元。
- 这些数值是组合覆盖概率，不是模型准确率；程序写入 `coverage_only=true`、`prediction_accuracy_claim=false`，并且不读取未来开奖结果。
- 期望支出只按固定的三至六等奖估算，故报告的 `expected_loss_upper_bound_yuan` 不包含浮动的一、二等奖，不能当成盈利承诺。

## 信号审计

为了避免把随机噪声当成预测能力，系统还会对 20 年真实数据执行独立的信号审计：

- 红球全局频率卡方：`p = 0.0851`。
- 蓝球全局频率卡方：`p = 0.9055`。
- 相邻两期红球重复数相对理论期望：`p = 0.6125`。
- 红球“上期出现/未出现”对下期条件概率差异：`p = 0.6070`。
- 频率模型年度 Top-10 覆盖对随机基线：`10` 年赢、`9` 年输；没有稳定方向。
- `2013–2014`、`2015–2016`、`2017–2018`、`2019–2020` 四个独立两年验证折均未出现稳定显著优势。

因此当前不把频率模型、长记忆模型或深度/树模型提升为正式预测器。严格模式继续回退随机基线；任何挑战者都必须先在固定的未来窗口通过预先设定的显著性门槛，不能根据测试结果反推上线。

运行 `make signal` 可重新生成 `reports/signal_audit.json`。

## 开发集挑战协议

新挑战者不再使用已经观察过的 `2021–2026` 测试段调参。`reports/challenger_protocol.json` 固定了五个 nested walk-forward 开发折叠，所有外层评估最晚结束于 `2020-12-31`：

- 随机基线被纳入候选集合，因此所有统计模型更差时可以明确 `abstain`，不会被迫选出一个“最不差”的模型。
- 当前五个折叠全部选择随机基线，正式未来挑战者为空，严格模型保持随机基线。
- `gap`、`recency_13`、`markov` 仅作为预注册探索面板，在开奖前一并冻结，未来可以积累真实证据，但不能根据开奖结果事后挑赢家。
- 正式晋级至少需要 `104` 期连续的开奖前冻结样本，并同时通过 NDCG@10 与红蓝联合对数损失的预设门槛。

运行 `make challenge` 可重建开发协议。历史折叠只能用于筛选和否定，不能替代未来盲测。

## 开奖前冻结账本

`src/lottery_lab/forecast.py` 将预测和结算物理分离：

- `forecasts/frozen/<期号>.json` 只包含开奖前预测、历史截止期号、数据 SHA-256、源码树 SHA-256 和模型选择状态。
- `forecasts/settled/<期号>.json` 在官方结果进入数据集后单独生成，引用原预测哈希；结算流程不会改写冻结文件。
- 同一期已存在的冻结文件只允许幂等读取，哈希不一致或文件名与目标期号不一致时直接失败。
- 当前 `2026134` 已在历史数据只到 `2026133` 时冻结，预测内容 SHA-256 为 `09bb1b26e3b997d20194acf3a51d90324eac03f18c098c5ff4b8409e76e7dcaf`。

本地 SHA-256 能发现意外修改，但能够重写全部本地文件的人也能重算哈希。要形成更强的反作弊证据，应在开奖前把冻结文件提交并推送到外部 Git 远端，或使用可信时间戳服务。

`reports/future_evidence.json` 只读取已冻结且哈希校验通过的预测及其独立结算 sidecar，不混入历史回放。后续新冻结文件会保存全部 33 个红球和 16 个蓝球概率，结算时计算 NDCG@10、Brier 和联合对数损失，再与同一期严格基线做配对 bootstrap。即使满足门槛，系统也只标记“可人工复核”，不会自动切换严格模型。

`2026134` 在增加全量概率字段之前已经冻结，因此保持原文件不变；开奖后仍会结算命中与奖级，但不补写缺失的 proper-score 字段，避免开奖后修复预测。完整未来评分样本从下一次新冻结开始累计。

## 任意区间严格回放

`period_review` 用于回答“系统在某个历史区间逐期会选出什么，以及真实开奖是什么”。选模窗必须完整早于回放窗；每期预测只使用该期之前的数据，预测完成后才读取当期真实结果。

默认示例是 `2026-01-01` → `2026-01-31`，选模窗 `2024-01-01` → `2025-12-31`：

```bash
make review
```

输出：

- `reports/period_2026_01.json`：全部模型逐期预测、历史截止期号、真实结果和汇总。
- `reports/period_2026_01.csv`：严格冠军与实验集成的逐期对照表。

当前 2026 年 1 月共 `13` 期。验证窗没有模型通过显著性门槛，严格冠军仍为随机基线：Top-10 红球覆盖 `11/13`，单注任何奖级 `0/13`，单注头奖 `0/13`。实验集成 Top-10 覆盖 `12/13`，单注任何奖级 `2/13`（均为六等奖），单注头奖 `0/13`；这不是显著预测能力。所有逐期预测的历史截止期号都早于当期期号，报告标记为事后严格回放，而不是当时已公证的预测。

## 数据底座与真实性

来源：

- 中彩网官方开奖信息：`https://jc.zhcw.com/port/client_json.php`，覆盖 2006 年至今。
- 中国福彩官网：`https://www.cwl.gov.cn/cwl_admin/front/cwlkj/search/kjxx/findDrawNotice`，用于 2013 年至今重叠段交叉复核。

采集脚本会：

1. 中彩网按 `100` 条/页抓取全部历史，官方接口按 `50` 条/页抓取重叠段；
2. 校验期号连续、日期递增、每期 6 个红球 1–33、1 个蓝球 1–16；
3. 对每个重叠期号逐期比对红球、蓝球和官方提供的一等奖注数/单注奖金；
4. 写出 `data/ssq_history.csv`、`data/manifest.json`、原始响应和 SHA-256；
5. 为每一期写出 `data/provenance.json`，记录规范化开奖哈希、每个原始来源记录哈希和双源/单源置信级别；
6. 只要出现缺期、重复、号码不一致或关键字段冲突就失败退出。

- 福彩官网原始响应 SHA-256：`5d64f27277a9365acb2a2743d9c3082a493d43b413dc186cd4716e4b58fbfbc7`

## 回测协议

- 每期先 `predict()`，再 `observe()`；当前期结果永远不进入当前期预测。
- 统计模型、频率、近因加权、遗漏、一阶转移、多因子集成、在线专家加权、在线逻辑回归均按时间顺序比较。
- 在线专家加权使用 Hedge 更新：每期先混合历史专家，再在结果揭示后按联合对数损失更新权重；它是预注册挑战者，不会因为历史回放结果自动替换严格基线。
- 在线逻辑回归的 SGD 梯度方向已有单元测试约束；此次修复后的旧测试段表现只用于诊断，不作为新的独立预测证据，模型仍需未来冻结窗口验证。
- 模型选择只看验证段；测试段只用于最终评估。
- 选择门槛：验证段 NDCG@10 相对随机基线的配对 bootstrap 95% 下界必须大于 0；否则回退随机基线。
- 2015 实验使用独立的 `2013–2014` 选模窗，2015 不参与任何选择或调参。

## 边界

本项目是概率教育、选号游戏和回测工具，不构成投注建议，不接真实支付。任何历史回测、数据飞轮或机器学习都不能把公平双色球下一期单注头奖准确率提高到 90%；本项目的 90% 只用于“Top-10 红球候选池覆盖”这一可定义、可复现的指标，并始终与单注真实命中率分开显示。
